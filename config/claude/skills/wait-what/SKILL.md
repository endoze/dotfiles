Wait, you lost me. Explain that again from zero. I know the product, not this code or this conversation.

- Keep only the one or two things I need right now. Drop side issues, caveats, file paths, line numbers, and test counts.
- Use everyday words. Replace every technical term, code name, and label (Q2, #2056, s1) with what it is in a few plain words. Name things by what I see or use, like the sign-in page or the deploy button.
- For domain words, use the ones in `GLOSSARY.md` (follow `GLOSSARY-MAP.md` to the right one if the repo has more than one), and give each one's plain meaning the first time it appears.
- Short sentences, one fact each. Say the literal thing. No analogies.
- Say whether it matters and whether I need to do anything.
- If you need an answer from me, end with one yes/no question and your pick.

If I say this twice, the last try still had a word I didn't know. Drop the glossary words too, and replace every remaining term with plain words.
